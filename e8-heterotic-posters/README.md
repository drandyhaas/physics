# E₈×E₈ heterotic posters

Two single-page posters (US Letter portrait, 612×792 pt), each authored as one
self-contained HTML file and exported to PDF.

| poster | source | PDF |
| --- | --- | --- |
| **E8 Static Poster** — the run from the Planck scale down to the Standard Model: compactification of 10-D string theory on a Calabi–Yau threefold, cosmic inflation, gaugino condensation breaking supersymmetry, gravity-mediated cross-talk between the two E₈ sectors, and the VEV cascade E₆ → SO(10) → SU(5) → SM. | [`E8.html`](E8.html) | [`E8 Static Poster.pdf`](E8%20Static%20Poster.pdf) |
| **E₈×E₈ Heterotic String Lagrangian** — the complete 10-D string-frame action in three lines, then broken out: the seven fundamental fields (metric, Kalb–Ramond 2-form, dilaton, the two E₈ gauge fields, and the fermions), colour-coded by sector. | [`E8_eq.html`](E8_eq.html) | [`E8×E8 Heterotic String Lagrangian.pdf`](E8%C3%97E8%20Heterotic%20String%20Lagrangian.pdf) |

## Viewing and rebuilding

The HTML files are self-contained — no build step, no assets, no network. Open
either one in a browser to view it. To regenerate the PDF, print to PDF at US
Letter with margins off and background graphics on.
